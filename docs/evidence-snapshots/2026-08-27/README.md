# Evidence snapshot — 2026-08-27

A full visual record of droppdd as it existed on this date, captured before
any public outreach (Reddit, etc.) went out. Purpose: an informal, dated
record of authorship and functionality — not legal protection, just a
matter-of-principle "this existed, working, before you saw it" reference.

**The stronger evidence is the git history itself**, not these images:
every feature below has a corresponding dated, hashed commit in this
public repo (github.com/nunchimangchi-dev/droppdd), timestamped by GitHub
as a neutral third party going back to the project's start. These
screenshots are a visual supplement to that record, not a replacement for
it.

One redaction: `12-admin-allowlist.jpg` has a real beta tester's personal
email blacked out — everything else is unedited. Screenshots
`02-dashboard.jpg`, `03-checkin.jpg`, `06-progress.jpg`, `07-wagers.jpg`,
`09-profile.jpg`, `14-admin-user-detail.jpg`, and `15-admin-data-rights.jpg`
show the maintainer's own real weight/health data and account details —
included deliberately, at the maintainer's own choice, since it's his own
data to disclose.
