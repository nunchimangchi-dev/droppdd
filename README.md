# droppdd

Aggressive fitness tracking and coaching: keto, one meal a day (OMAD),
instructed workouts, and AI-assisted meal planning.

This repo is currently a scaffold — Next.js app running, nothing built yet.
It exists first as the validation case for [skyrise](https://github.com/nunchimangchi-dev/skyrise),
proving the dev environment/toolchain end to end on a real project.

## Stack

TypeScript, Tailwind CSS, Next.js App Router, ESLint, npm.

## Development

```sh
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Status

Scaffold only — see the [skyrise dashboard](https://box.tail2b3f17.ts.net/) for
what's built so far and what's next.
